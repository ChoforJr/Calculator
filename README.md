# Calculator

Calculator project for The Odin Project.

## Build

Install the development dependency and compile the source files:

```sh
npm install
npm run build
```

The browser loads the generated files from `dist/`. Keep source files in the
project root; JavaScript can remain alongside TypeScript while the migration
is in progress.

## Features

- Chained arithmetic, decimals, percentages, sign toggle, and repeat equals
- Keyboard support for numbers and operators, Enter, Backspace, and Escape
- Responsive layout with accessible button labels and display announcements
- Division-by-zero and non-finite results are reported as errors
